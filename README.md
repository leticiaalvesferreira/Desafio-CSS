# 🎨 Desafio CSS

Este repositório contém a resolução de um desafio focado no desenvolvimento e estilização de páginas web utilizando HTML5 e CSS3. O objetivo principal do projeto é praticar e aprimorar conceitos fundamentais de desenvolvimento front-end, estruturação semântica e estilização visual.

# 📌 Sobre o Projeto

O projeto foi desenvolvido para consolidar aprendizados práticos de estilização CSS. Ele demonstra a aplicação de boas práticas de estruturação de layout, manipulação de cores, tipografia e organização de elementos na página.

# 🛠️ Tecnologias Utilizadas

HTML5: Estruturação semântica da página.

CSS3: Estilização, layout e design responsivo.

# 💻 Aprendizados e Destaques

Durante o desenvolvimento deste desafio, foram praticados os seguintes conceitos:

- [x] Estruturação semântica com tags HTML5.

- [x] Aplicação de regras de estilo CSS (seletores, classes e IDs).

- [x] Modelo de caixa (Box Model — margens, espaçamentos internos e bordas).

- [x] Estilização de fontes e textos.

- [x] Posicionamento e alinhamento de elementos na tela.
